# Security Policy

## Supported versions

The current `main` branch is supported.

## Data handling

This project is a synthetic portfolio prototype. It must not contain:

- Call detail records, message payloads, IMSI/MSISDN values, or customer identifiers.
- Private carrier contracts, topology maps, peering details, or production route tables.
- API credentials, SSH keys, certificates, passwords, or deploy secrets.

## Reporting

Open a GitHub issue for non-sensitive security concerns. Contact the repository owner privately for sensitive issues.
